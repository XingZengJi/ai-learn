# notes/ · 费曼笔记

`Course/` 放的是课程笔记（译述或自写的课堂记录），这里放的是**学完之后，自己能不能讲出来**的检验。

点亮一颗星只说明测验答对了。四选一的题，认得出正确答案就够了，**讲得出来**是另一回事。费曼法就是逼自己从「认得」走到「讲得出」。

## 怎么练（一次 15 分钟）

1. **挑一颗星**，优先级：
   - 网站学习助手条提示「温习 · N 颗星到期」里的星（点亮满 30 天，正好拿来检验）
   - 错题本里反复出现的知识点
   - 你觉得「懂了但说不清」的
2. **合上笔记**，照 [`费曼笔记模板.md`](费曼笔记模板.md) 写。写不下去的那一句，就是没懂的地方，标出来
3. **再打开笔记**，只补卡住的那几处，并写下原来哪里理解错了
4. 回网站把这颗星的测验做一遍，对照自己写的内容

**纪律**：第 2 步不许翻笔记、不许问 AI。让 AI 代写费曼笔记，等于让别人替你健身。AI 可以在第 4 步之后当「挑刺的外行」：把你的笔记发给它，让它找出说不通的地方。

## 命名

- Anthropic 知识点：`kNNNN-简称.md`，如 `k0702-CLAUDE.md怎样才被遵守.md`
- OpenAI 知识点：`openai-kNNNN-简称.md`（两个厂商的知识点 ID 格式一样，会撞号）
- 知识点 ID 和名称以 `docs/data/<厂商>/knowledge.json` 为准，也可以在网站上点开那颗星看

## 注意

本仓库是公开仓库。这里只写对知识的理解，**不写客户、工作项目或其他不该公开的细节**。
