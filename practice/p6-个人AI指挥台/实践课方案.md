# 个人 AI 指挥台 · 实践课方案

> 定位：Claude 101（c01）+ Claude Cowork 入门（c03）的综合实战项目，成就地图 **p6**，级别 L1「会用」。
> 制定日期：2026-07-27
> 载体任务：**行业/竞品动态周报**（你本来就在做、且会持续做的事）
> 玩法：**你开车，Claude 当教练**——这门课的「亲手做」不是敲代码，是**在 Claude 桌面应用里点**。c01/c03 的 15 个知识点全是产品功能，读文档等于没学。
> 成果绑定：完成后点亮 p6 行星。

---

## 一、项目蓝图

把「每周扫一遍关注的产品和信息源、写一份简报」这件事，从**每次打开对话框重新说一遍**，变成一个已经配置好、会自己跑的工位：

```
claude.ai 侧（Chat）
  Project「行业周报」──── 自定义指令 + 关注对象清单 + 历史简报（记忆自动积累）
        │
        ├─ Research 模式 ──── 深度调研，带来源
        └─ Artifact ──────── 一页可分享的简报模板
        │
桌面应用侧（Cowork）
  projects/weekly-report/ ── 任务专属文件夹（= 它能看见什么、能改什么）
        ├─ Skill「周报格式」 ── 你的编辑标准固化成资产
        └─ 定时任务 ────────── 每周自动出稿
        │
  《我给 Claude 划的边界》── 哪些文件夹给它、哪些不给、为什么
```

做完之后你得到：一份**真的每周在出**的周报 + 一次「把重复劳动交出去」的完整体验。

**验收线（两周后回看）**：连续两周，这份周报**不用你重新解释一遍需求**就能出稿。做不到就说明工位没搭成，只是用了几次 AI。

## 二、教练规则

1. **必须你亲手做的**：每一条提示词、建 Project、开 Research、选 Cowork 的文件夹、写全局指令、建 Skill、配定时任务。教练可以给「提示词模板」，但你要理解后自己改写再发出，**禁止原样复制**。
2. **教练做的**：每阶段开场讲清「今天用哪些知识点、为什么」；你卡住时先指路到课次笔记（`Course/Claude/01Claude101/`、`Course/Claude/04Cowork/`，这两门的笔记只在本地、不公开）让你自己翻，翻完还不会才直接讲；阶段结尾带你过回收清单。
3. **这门课特有的一条**：**功能不是用来打卡的**。每个功能用完，你要能回答「这件事不用它会怎样」。答不上来说明只是点了一遍按钮。
4. 每阶段结束：向教练**口头讲一遍今天每个功能解决了什么问题**（费曼检查）。讲不清的标记出来。

## 四、四阶段教案

### 阶段 1 · 立项与裸跑基线（约 1 小时）

**学习目标**：先确认这件事到底适不适合交出去；建立一条「没配置过的 Claude 有多难用」的基线，后面每一步的价值都靠和它对比才看得出来。

**你的操作清单**：

1. **先验任务，别急着动手**（c03 第 3 课）。拿你的周报对着三个适配特征逐条打勾：
   - **多步骤**？（扫信息源 → 筛选 → 归纳 → 成稿，不是一问一答）
   - **文件为本**？（有素材文件、有产出文件，不是聊完就完）
   - **跨工具**？（网页、文档、可能还有表格）

   三条都中才继续。**只中一条的话现在改比做到一半改省事**——那种任务 Chat 就够了。
2. **写下关注对象清单**：哪些产品、哪些公众号/媒体、哪些人。这份清单是整个项目的燃料，先手写出来（10–20 条），别让 AI 替你想——它不知道你真正在盯谁。
3. **裸聊一次**（k0101）：打开 Claude，不建 Project、不给任何背景，直接要一份本周简报。**存下这次结果**，这是你的对照组。
4. 用**三要素**改写提示词再来一次（k0102）。模板（理解后自己改写）：
   > 【场景】我是 PM，每周要给自己出一份行业动态简报，关注对象是 ⟨清单⟩。【任务】按「本周发生了什么 → 谁受影响 → 我该注意什么」三段成稿，每段控制在 200 字内。【规则】每条结论必须带来源链接；查不到出处的具体数字直接标「未核实」，不要写进正文。
5. 迭代 2–3 轮（「第二段太泛」「按影响排序」），**把每次你需要纠正的点记在纸上**——阶段 2 建 Project 时这些就是自定义指令的原材料。
6. **三模式各做一遍**（k0103）：同一件事分别在 **Chat**、**Cowork**、**Code** 里试着开个头，写下各自的手感差异。不用做完，只需体会「Chat 用来想，Cowork 用来做」。

**教练检查点**：三个适配特征是不是真逐条验了（含否定项）｜提示词是否真有三要素｜纸上的纠正点是不是具体到能直接抄进指令

**知识点回收清单**：
- [ ] 我这件事符合哪几个适配特征，不符合的是哪条（c03 L03）
- [ ] 三要素各是什么，裸聊版差在哪（k0101 / k0102）
- [ ] Chat / Cowork / Code 各自什么时候用（k0103）

### 阶段 2 · 建工位：Project + Research + Artifact（约 1.5 小时）

**学习目标**：让「每次重新解释」这件事彻底消失；分清「搜一下」和「深度调研」的区别。

**你的操作清单**：

1. **建 Project「行业周报」**（k0104）：
   - 把阶段 1 纸上那些纠正点，写进**自定义指令**
   - 把关注对象清单、过往写过的简报传进项目知识
   - **关键认知**：Project 的最大红利是**记忆自动积累**，前提是相关工作确实持续发生在这个项目里。零散地开新对话，这层红利永远攒不起来
2. **在 Project 里重出一版简报**，和阶段 1 的裸聊版并排比。**差距就是配置的价值**，把它记下来——这是你以后说服别人用 Project 的证据
3. **Research 模式跑一次深度调研**（k0107）：挑清单里最重要的一个对象，让它做一次完整调研。观察三件事：
   - 它的**调研计划**长什么样（和你自己会怎么查有何不同）
   - 耗时明显更长——**这是特性不是 bug**
   - **来源清单**：随机挑 3 条点开核对。查不到出处的具体细节是**警示信号，不是加分项**（c03 L04 原话）
4. **做一个 Artifact 周报模板**（k0105）：让它把简报格式做成一个可分享的页面/文档。改 2 轮，直到你愿意把链接发给别人
5. **连接工具**（k0106）：接一个你实际会用的连接器（如 Google Drive / Notion，看你手上有什么）。⚠️ **企业搜索需要 Team/Enterprise 席位**，没有的话做替代动作，见第五节

**教练检查点**：Project 版和裸聊版的差距你能否具体说出 3 条｜Research 的来源你是否真点开核对了｜Artifact 是否到了「敢发给别人」的程度

**知识点回收清单**：
- [ ] Project 的自定义指令和项目知识分别装什么（k0104）
- [ ] Research 和普通提问的三点区别（k0107）
- [ ] 「查不到出处的具体细节是警示信号」——我核出问题了吗（k0107）

### 阶段 3 · 交给 Cowork：从对话到委托（约 2 小时）

**学习目标**：完成全课最核心的心智转变——**委托，而不是对话**。

**你的操作清单**：

1. **装好并设置 Cowork**（k0301）
2. **先建任务专属文件夹**，再开任务（k0302）：
   ```
   ~/workspace/projects/weekly-report/
     素材/      ← 你收集的原始材料
     历史简报/  ← 过往产出
     本周/      ← 这周的工作区
   ```
   **选文件夹是每次任务里最关键的一步设置**——它同时定义了 Claude 能看见什么、能改什么。新手最容易犯的错是图省事把整个「文档」目录丢给它。**你要反过来做。**
3. **交出第一个完整任务**（k0302）。一个好提示词做三件事：**点名交付物、点名素材来源、点名专业判断**。
   > 把 `素材/` 下这周的材料整理成一份简报，写进 `本周/周报-⟨日期⟩.md`。格式参照 `历史简报/` 里最近三份。**哪些条目值得放进正文由你判断**，判断依据一并写在文末。
4. **审查成品**：逐条核对来源。这一步不能省——委托不等于放手。
5. **写全局指令**（k0303）：「你是谁」这一层。你的岗位、你写东西的习惯、你讨厌什么风格。
   - **全局指令覆盖你，项目覆盖你正在做的事**——想清楚每条规则该放哪一层
6. **把周报格式做成 Skill**（k0108 + k0304）：
   - 阶段 1–3 你已经反复交代同一套格式要求了——**「同一段多步骤指令打过两遍字，就是该做 Skill 的信号」**
   - Skill 的四类文件：**指令 / 素材 / 参考 / 脚本**。跟着实际需要走，不必四件套齐全
   - 建好后**读一遍它的描述**，确认写清了触发时机——Skill 不触发，原因几乎总是描述写得不好
7. **让 Skill 真的触发一次**：新开一个任务，只说「出这周的周报」，看它有没有自动照 Skill 做。**没触发就改描述再试**——这个来回你必须走一次

**教练检查点**：文件夹是不是任务专属的（给了整个「文档」目录=没懂）｜提示词是否点名了「专业判断」｜Skill 是否真被自动触发过（含失败重试）

**知识点回收清单**：
- [ ] 「委托，而不是对话」具体差在哪（c03 L01）
- [ ] 为什么选文件夹是最关键的一步设置（k0302）
- [ ] 全局指令 / 项目 / Skill 三层各装什么（k0303 / k0108）
- [ ] 我的 Skill 第一次没触发是因为什么（k0304）

---

### 阶段 4 · 自动化与收边界（约 1.5 小时）

**学习目标**：让它不用你按开关也能跑；同时想清楚你把什么权限交出去了。

**你的操作清单**：

1. **配定时任务**（k0307）：每周固定时间自动出稿。
   - 注意细节：**定时任务「留在创建它的地方」**——在哪建的就在哪跑
   - ⚠️ 若你的账号档位没有这个功能，做替代动作，见第五节
2. **Claude in Chrome**（k0305）：判断标准是——「只要你在想*真希望能把这个上下文给 Claude，可它偏偏在网页上*」。你收集素材时大概率天天遇到。
   - **安全认知**：**Claude 能看到的和你能看到的一致**。给它浏览器权限，本质是在扩展你自己权限能触达的范围——包括你登录着的一切
   - ⚠️ M365 集成需要订阅，没有的话做纸面对比即可
3. **写《我给 Claude 划的边界》**（k0306），这是本项目的收官交付物。四个问题必须有答案：
   - 哪些文件夹**永远不给**？为什么？
   - 哪些内容**不能进** Project 知识库？（客户名单？内部数据？）
   - 这份周报如果要发给别人，**要不要标注 AI 参与**？标到什么程度？
   - 出了错，**谁负责**？
4. **连续两周实跑**——这是真正的验收，不是走流程。两周里记录：
   - 每周你还需要人工干预几次？干预的是什么？
   - 有没有哪一周它出错了？错在哪个环节（素材/判断/格式）？
5. **收尾三件套**：
   - 回 ai-learn 说「**点亮 p6**」
   - 写复盘到本目录 `复盘.md`：假想向一位没用过 Claude 的同事讲清这个工位怎么运转
   - 教练按覆盖矩阵逐项验收

**教练检查点**：边界文档是不是真回答了四个问题（写「注意安全」等于没写）｜两周实跑是否真跑了（这条不能提前结课）

**知识点回收清单**：
- [ ] 定时任务的「留在创建它的地方」是什么意思（k0307）
- [ ] 给浏览器权限本质上给出去了什么（k0305）
- [ ] 我的四个边界问题，答案分别是什么（k0306）
- [ ] 能向没用过 Claude 的人完整讲清这个工位（毕业标准）

## 五、两个受账号限制的知识点

规划书第六节已列明，这里给具体替代动作。**做不了就如实标注，不装作做了。**

| 知识点 | 限制 | 替代动作 |
|---|---|---|
| **k0106** 企业搜索 | 需 Team / Enterprise 席位 | 接一个普通**连接器**并真用起来；然后写清「连接器」与「企业搜索」的区别：前者是你**主动接一个数据源**，后者是**跨公司已有系统统一检索**。写进阶段 2 的笔记 |
| **k0305** M365 集成 | 需 M365 订阅 | **Chrome 部分照做**（这部分不需要额外订阅）；M365 部分做纸面对比，记住那条选择标准：**多来源产出一份交付物用 Cowork，就地编辑用 M365 里的 Claude**——两者常配合使用，文件在两边是同一份 |

另：**Cowork 与定时任务的可用性取决于你的账号档位**。开工前先确认；若定时任务不可用，替代动作是**写一份「每周一手动触发」的检查清单**并连续执行两周——自动化程度降级，但「委托闭环」这个核心体验不受影响。

## 六、开工方式

每个阶段单开一次会话，开场对教练说：**「个人 AI 指挥台，开始阶段 N」**——教练会读本方案，按当阶段教案带练。中途隔几天没关系，方案就是存档点。

**阶段 1 的第一件事是验任务**。如果三个适配特征验下来不满足，教练会直接告诉你，那时换一件事做，比硬做完再发现划算。
